# Contribuir a BCRP Downloader

1. Haz un fork del repositorio y crea una rama desde `main` (`feat/mi-cambio`, `fix/mi-correccion`).
2. Instala las dependencias: `pip install -r requirements.txt`.
3. Realiza tus cambios y agrega o actualiza pruebas en `tests/`.
4. Ejecuta `python -m pytest -q` y asegúrate de que pasen (las pruebas de red pueden omitirse).
5. Usa [Conventional Commits](https://www.conventionalcommits.org/) para los mensajes (`feat:`, `fix:`, `docs:`, `test:`, `chore:`).
6. Abre un Pull Request describiendo el cambio.

Al contribuir aceptas que tu aportación se licencie bajo la GNU GPL v3 o posterior.
