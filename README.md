# BCRP-Downloader
BCRP Downloader es una aplicación de escritorio monolítica y minimalista en Python/Flet para la exploración, consulta y extracción automatizada de series estadísticas del Banco Central de Reserva del Perú. Integra búsqueda reactiva por metadatos oficiales y exportación directa de datos macroeconómicos a formato CSV.
