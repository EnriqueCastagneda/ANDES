# Política de seguridad

## Versiones soportadas

| Versión | Soporte |
| --- | --- |
| 2.x | Sí |
| 1.x | Solo correcciones críticas |

## Reportar una vulnerabilidad

No abras un issue público. Usa una de estas vías:

1. **GitHub Security Advisories**: pestaña *Security* → *Report a vulnerability*.
2. Correo: **EnriqueCastagneda@protonmail.com**.

Incluye:

- Versión de ANDES y sistema operativo.
- Pasos para reproducir.
- Impacto esperado.
- Prueba de concepto, si existe.

## Alcance

- Ejecución de código o escalada de privilegios.
- Exposición de datos locales o credenciales.
- Inyección en consultas o rutas.
- Denegación de servicio en la app o sus adaptadores.
- Suplantación de la identidad de marca.

## Fuera de alcance

- Vulnerabilidades en portales externos (BCRP, MEF, INEI, Gob.pe).
- Contenido o licencias de los datos de terceros.
- Configuraciones locales inseguras del usuario.

## Compromiso

Confirmaremos la recepción en un plazo razonable, coordinaremos la corrección
y publicaremos el aviso cuando exista una versión corregida.
